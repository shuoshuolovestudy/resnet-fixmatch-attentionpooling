# 基于半监督学习的植物病害识别系统

## 项目简介

本科毕业设计，采用 **FixMatch** 半监督学习框架结合 **Attention Pooling** 注意力机制，
在仅使用 **5%标注数据** 的条件下，达到 **90.79%** 识别准确率。

> 郑州轻工业大学 | 软件工程（新型平台软件）22-03 | 2026届

---

## 核心方法

| 模块 | 说明 |
|------|------|
| **FixMatch** | 弱增强生成伪标签，强增强下强制一致性约束 |
| **Attention Pooling** | 替换ResNet18顶层全局平均池化，通过1×1卷积学习空间权重，聚焦病斑区域 |
| **损失函数** | 监督损失 + λ·无监督损失 |


数据集：PLantVillage（公开数据集，约5.4万张，38类植物病害）
来源：Kaggle - PlantVillage
论文：Hughes & Salathé, arXiv:1511.08060, 2015
